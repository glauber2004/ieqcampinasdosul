# ✝ Igreja do Evangelho Quadrangular · Campinas do Sul

Site da nossa igreja, feito com **HTML, CSS e JavaScript** e publicado no **GitHub Pages**.

## O que tem no site

- 📖 **Nossa História**: carrossel de imagens
- 👥 **Lideranças**: grupos com foto, nome e cargo
- 🎉 **Eventos**: batismos e outros eventos, com fotos e vídeos
- ⛪ **Cultos**: organizados por ano (2026 a 2030), mês e domingo
- 🌐 **Redes sociais**: Facebook, Instagram, YouTube e Gmail
- 🎥 **Equipe de Mídia**: quem cuida das fotos, vídeos e do site

## Estrutura

```
index.html   → estrutura da página
style.css    → cores e visual
dados.js     → todo o conteúdo (é aqui que se edita)
script.js    → funcionamento do site
assets/      → fotos e vídeos (cultos/ano/mês/data)
```

## Como atualizar

1. Coloque a foto ou vídeo na pasta certa em `assets/`.
2. Registre o nome do arquivo no `dados.js`.
3. Envie para o GitHub. O site atualiza sozinho.

> 💡 Vídeos grandes: use o link do YouTube em vez de enviar o arquivo.

## Publicar

**Settings → Pages → Deploy from a branch → `main` → `/ (root)`**
